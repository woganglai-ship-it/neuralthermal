NT API Studio · API 开发者中心

把热模型接进客户的研发流程

客户的软件把参数发给 NT，几毫秒拿回温度和分析结果。本页以示意冷板为例，所有数字都是仿真或代理模型的结果。

API 怎么工作

客户的软件选型工具、优化程序、智能体
参数（JSON）
+ API 密钥
NT 服务器客户专属热模型
权重和代码不出服务器
结果（JSON）
回到客户流程温度、温度场、压降、报警、方案排序

客户不用打开我们的网页，也不用装我们的软件。在约定的结构和参数范围内，每次调用都不用重新建模、划网格、跑完整求解；超出范围时 API 会拒绝，并提示需要扩展模型。

三类服务

NT Design · 热预测

快速比较大量设计方案

客户提交
功耗、流量、进水温度、可调的结构参数
NT 返回
最热点温度、温度场、压降

NT Sensor · 虚拟温度传感

算出测不到的温度

客户提交
运行数据：功耗、泵流量、进水温度、负载类型
NT 返回
芯片最热点温度曲线和过热报警

NT Workflow · 批量分析

把重复筛选自动化

客户提交
参数范围、约束、优化目标
NT 返回
方案排序、候选设计、可下载的报告

示例：一家液冷冷板厂商（虚构）

1

首次建模与验证

用客户的仿真和测试数据训练专属模型，按约定的精度验收。本演示用 3,000 次求解器计算训练，测试集上最热点平均误差 –。

2

年度使用

客户的选型软件输入功耗、流量、进水温度，直接调用 API。按年度套餐计调用次数；本页调用计数仅演示，不计费。

3

扩展

新型号、更大的参数范围、全新的冷板结构，需要补充仿真、更新模型，单独报价。

官网负责让客户看懂，试点负责证明价值，API 负责让客户长期使用。

      金额待定。工程客户主要为精度、适用范围、集成支持和持续可用性付费，所以以年度套餐为主，而不是按每次调用几分钱收费。
      
    
      边界
        
      
      • 模型在服务器上运行，客户只拿到输入和输出，不交付训练代码和模型权重；但不能保证绝对无法逆向。
        • 
      
      • 每次调用都有 request_id 和模型版本号，方便追溯；超出已验证范围时直接拒绝，不硬给数字。
        • 
      
      • 本演示的模型是示意冷板，不是任何客户的产品；芯片实验室是免费演示入口，也不能直接包装成收费的预测服务。
